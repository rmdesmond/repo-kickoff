# 0004: Licence the project under MIT

Date: 2026-11-24
Status: accepted

## Context

The repository needs a licence, chosen by the owner when the plan was accepted.

## Decision

Use the MIT licence, with Randall Desmond as the copyright holder. The text is in `LICENSE`.

## Consequences

Anyone given access may use, copy, modify and distribute the code, keeping the copyright notice. A different licence later needs a new record.
