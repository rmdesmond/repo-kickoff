## Testing

```sh
ctest --test-dir build --output-on-failure   # CMake 3.20 or later
(cd build && ctest --output-on-failure)      # any CMake version
tests/smoke.sh                               # builds in a temporary folder, checks the program, runs ctest
```

The unit tests are built by default, and need GoogleTest. Without it, configuring stops with a message saying how to get it. To build only the program, configure with `-D{{NAME_SNAKE}}_BUILD_TESTS=OFF`. `tests/smoke.sh` always builds and runs the unit tests.

## Getting GoogleTest

The build looks for an installed copy first (`find_package(GTest)`). Install one with:

```sh
brew install googletest              # macOS, Homebrew
sudo apt install libgtest-dev        # Debian, Ubuntu
```

Or let CMake download it, by opting in when you configure:

```sh
cmake -S . -B build -D{{NAME_SNAKE}}_FETCH_GOOGLETEST=ON
```

This downloads GoogleTest 1.15.2 with `FetchContent`, checked against its SHA-256, and only when no installed copy is found. The option is off by default, so a normal build never touches the network, and `tests/smoke.sh` always turns it off.
