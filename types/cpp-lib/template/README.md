## Building

Build in a separate folder, never in the source tree:

```sh
cmake -S . -B build
cmake --build build
```

This builds a static library, `build/lib{{NAME_SNAKE}}.a`. For a shared one (`.so` on Linux, `.dylib` on macOS), configure with `-DBUILD_SHARED_LIBS=ON`:

```sh
cmake -S . -B build-shared -DBUILD_SHARED_LIBS=ON
cmake --build build-shared
```

## Testing

```sh
ctest --test-dir build --output-on-failure   # CMake 3.20 or later
(cd build && ctest --output-on-failure)      # any CMake version
tests/smoke.sh                               # the whole round trip, in a temporary folder
```

The tests are registered with `gtest_discover_tests`, so CTest lists each GoogleTest test separately. Without GoogleTest, configuring stops with a message saying how to get it. To build the library without its tests, configure with `-D{{NAME_SNAKE}}_BUILD_TESTS=OFF`.

## Getting GoogleTest

The build looks for an installed copy first (`find_package(GTest)`). Install one with:

```sh
brew install googletest              # macOS, Homebrew
sudo apt install libgtest-dev        # Debian, Ubuntu
```

Or let CMake download it, by opting in when you configure:

```sh
cmake -S . -B build -D{{NAME_SNAKE}}_FETCH_GOOGLETEST=ON
```

This downloads GoogleTest 1.15.2 with `FetchContent`, checked against its SHA-256, and only when no installed copy is found. The option is off by default, so a normal build never touches the network, and `tests/smoke.sh` always turns it off.

## Choices made for you

- Everything is in namespace `{{NAME_SNAKE}}`, and the public header lives under `include/{{NAME_SNAKE}}/`, so it's included as `<{{NAME_SNAKE}}/{{NAME_SNAKE}}.hpp>` and can't clash with other libraries' headers. `{{NAME}}` is the CMake project and package name; `{{NAME_SNAKE}}` is used for C++ identifiers, file names and CMake targets, which can't contain dashes.
- C++17 is a `PUBLIC` compile feature of the library, so programs that link it are compiled as C++17 or later too.
- The library is static by default (`BUILD_SHARED_LIBS=OFF`) and built position-independent, so it can also be linked into someone else's shared library. Shared builds work on macOS and Linux; Windows DLLs would need export macros, which aren't set up.
- The tests are built only when this is the top-level project, or with `-D{{NAME_SNAKE}}_BUILD_TESTS=ON`. When they're built, GoogleTest is required; downloading it is opt-in, never automatic.
- The version comes from `project(... VERSION ...)` in `CMakeLists.txt` and is compiled into the library; `version()` returns it. The installed package accepts any request with the same major version (`SameMajorVersion`).
- Warnings (`-Wall -Wextra -pedantic`) are on for gcc and clang, but don't fail the build.
